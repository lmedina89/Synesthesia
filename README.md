# Garden Notes v0.9 — GitHub Pages release

Upload the **contents** of this folder to the root of your existing GitHub Pages repository. `index.html` is the application. `example-song.mid` is a synthetic original test track.

v0.9 improves scrolling staff note locations, ledger lines and chord legibility, and extracts testable music/practice modules. Real piano audio, kalimba, immersive practice and personal MIDI import/export are retained.

The two third-party game song arrangements are NOT included. Imported songs should remain in the same site's browser storage, but keep your personal MIDI backups.

The displayed pitches are accurate to the MIDI note numbers, but printed rhythm/staff assignment is still approximated. Actual iPhone Safari testing and audio scheduling improvements remain future work.

Refer to LICENSE_SAMPLES.md for real-piano sample attribution.
